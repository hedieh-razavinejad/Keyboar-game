# کلیدار

بازی حدس حرف فارسی با Vue 3 و Tailwind CSS.
از ۳۰ حرف، ۹ تا مین است، یکی حرف هدف و ۲۰ تا حرف امن. اسم بازیکن اول گرفته می‌شود و پیام‌ها با اسم او نوشته می‌شوند.

## اجرا

```bash
npm install
npm run dev      # اجرای محلی
npm run build    # ساخت نسخهٔ نهایی در پوشهٔ dist
npm run preview  # دیدن نسخهٔ ساخته‌شده
```

نیاز به Node.js نسخهٔ ۱۸ یا بالاتر دارد.

## قوانین بازی

| اتفاق | نتیجه |
|---|---|
| زدن حرف هدف | برد و امتیاز (۱۰۰ به‌اضافهٔ ثانیه‌های باقی‌مانده) |
| زدن حرف عادی | ۲ ثانیه از زمان کم می‌شود |
| زدن مین | یک جان از ۳ جان کم می‌شود |
| ورودی نامعتبر (عدد، چند حرف، حرف غیرفارسی، حرف تکراری) | کادر می‌لرزد و خالی می‌شود، چیزی از بازیکن کم نمی‌شود |
| تمام شدن ۲ دقیقه یا ۳ مین | باخت |

کادر ورودی بزرگ است و درست زیر جعبهٔ حروف قرار دارد. فقط حروف فارسی را می‌پذیرد و حرف تکراری را رد می‌کند. هر جای صفحه که روی کیبورد خودت تایپ کنی، حرف در کادر می‌نشیند و همان کلید داخل بازی هم زده می‌شود. روی دسکتاپ کیبورد بازی بزرگ‌تر است.

در پایان هر دور، یک واریاسیون با اسم فارسی نشان داده می‌شود (مثل «تیرِ اول» یا «از دلِ آتش») و تا سه ستاره.

## ساختار فایل‌ها

```
index.html                  صفحهٔ اصلی (راست‌به‌چپ، فونت‌ها)
package.json                وابستگی‌ها و دستورها
vite.config.js              تنظیم Vite با افزونهٔ Vue
tailwind.config.js          فونت، انیمیشن‌ها و مسیر فایل‌هایی که Tailwind می‌خواند
postcss.config.js           Tailwind و Autoprefixer
src/
  main.js                   ساخت برنامهٔ Vue
  style.css                 دستورهای Tailwind، پس‌زمینه و ظاهر کلیدها
  data.js                   حروف، متن پیام‌ها، واریاسیون‌ها، عددهای ثابت
  composables/useGame.js    همهٔ قوانین و وضعیت بازی
  App.vue                   چیدمان صفحه
  components/
    LoginScreen.vue         صفحهٔ ورود (ربات با تایپ و خطا واکنش نشان می‌دهد)
    NameScreen.vue          صفحهٔ گرفتن اسم با سه ربات
    RobotTrio.vue           سه ربات کنار هم؛ فقط یکی بیدار است
    FloatLetters.vue        حرف‌های شناور پس‌زمینه
    KeyCap.vue              یک کلید کیبورد
    StatusBox.vue           جعبهٔ پیام سیستم
    ResultModal.vue         کارت پایان بازی
```

قانون‌ها در `useGame.js` هستند و کامپوننت‌ها فقط وضعیت را نشان می‌دهند. برای عوض کردن زمان، تعداد جان‌ها یا حرف‌های امن (`SAFE_COUNT`) فقط بالای `data.js` را تغییر بده. تعداد مین از روی آن حساب می‌شود؛ اگر بازی سخت بود `SAFE_COUNT` را بیشتر کن.

## چیزهایی که استفاده شده

- **Vue 3** با Composition API و `<script setup>`: `ref`، `reactive`، `computed`، `defineProps`، `defineEmits`، `v-for`، `v-if`، `v-model`.
- **Vite 5** برای اجرا و ساخت، با `@vitejs/plugin-vue`.
- **Tailwind CSS 3.4** با PostCSS و Autoprefixer: کلاس‌های ابزاری، مقدارهای دلخواه مثل `shadow-[0_0_14px_...]`، کلاس‌های منطقی راست‌به‌چپ مثل `border-s-4`، و انیمیشن‌های `shake` و `pop` در تنظیمات.
- **CSS ساده** فقط برای کلیدها: لایهٔ پایه، سطح گود رویی، حک حرف، نور زیرین و چرخش سه‌بعدی کیبورد با `perspective`.
- **فونت:** Vazirmatn از Google Fonts. اگر فونت شبنم روی دستگاه نصب باشد همان نشان داده می‌شود و در غیر این صورت وزیرمتن.
- هیچ ذخیره‌سازی‌ای در مرورگر (localStorage و مانند آن) استفاده نشده است.

## کارهایی که انجام شد

1. نسخهٔ اول تک‌صفحه‌ای با کاشی و تایمر ساخته شد.
2. بازی ساده‌تر و به رنگ نانی شد؛ اسم بازیکن، جعبهٔ حروف زده‌شده و پاک شدن کادر برای ورودی غلط اضافه شد.
3. رنگ نوشته‌ها سرمه‌ای و خط‌ها نانی شد و کیبورد چهارگوش شد.
4. طراحی بر اساس عکس‌های نمونه به حالت تاریک و نئونی رفت.
5. بازخورد هر کلیک مطابق فایل‌های راهنما ساخته شد: هدف با درخشش فیروزه‌ای، حرف عادی با فلاش کهربایی و ۲ ثانیه کم، مین با حاشیهٔ قرمز و کم شدن یک قلب.
6. سرنخ «یخ‌زده/سوزان» برداشته شد، چون در فایل‌های راهنما نبود.
7. پیام‌ها و صفحهٔ پایان به فارسی روان بازنویسی شد و دایرهٔ بی‌کار بالای صفحه برداشته شد.
8. کد جاوااسکریپت ساده شد و ظاهر با Tailwind ساخته شد.
9. کلیدها با الهام از کامپوننت `keycap-orb` به کیک‌کپ‌های برجسته با نور کبالتی تبدیل شدند. خود آن کامپوننت (WebGL و React) در این پروژه نیست، فقط ظاهرش با CSS ساخته شده.
10. نسخهٔ نهایی به پروژهٔ Vue و Tailwind تبدیل شد.
11. رنگ‌بندی سرمه‌ای حفظ شد و دکمه‌ها و کلیدها سرمه‌ای شدند. فقط رنگ «اشتباه» (حرف عادی، پیام خطا و ثانیهٔ کم‌شده) نانی است. رنگ‌های نانی در `tailwind.config.js` با اسم `bread` تعریف شده‌اند و رنگ کلیدها در `src/style.css` است.
13. چیدمان کلیدها مثل کیبورد فارسی استاندارد شد (سه ردیف، با جابه‌جایی ردیف‌های پایین؛ «ظ» و «ژ» در بازی نیستند). تا وقتی حرفی در کادر ورودی است، حرف دیگری قبول نمی‌شود و بعد از پاک شدنِ آن، حرف بعدی پذیرفته می‌شود.
12. ورودی بزرگ زیر جعبهٔ حروف، فقط حروف فارسی بدون تکرار، تایپ با کیبورد واقعی که کلید بازی را هم می‌زند، کیبورد بزرگ‌تر در دسکتاپ، ۳ جان و ۲۰ حرف امن.
14. سه ربات (اخمو، خوشحال، لپ‌تاپ‌به‌دست) زیر کیبورد، در جای خالی سمت چپ، گذاشته شد: لپ‌تاپ‌دار هنگام تایپ، اخمو بعد از هر اشتباه و خوشحال بعد از پیدا کردن هدف. عکس‌ها در `src/assets/robots` و کامپوننت‌هایشان `Robot.vue` و `SideNote.vue` هستند. `SideNote.vue` پیام کوتاه و کوچک را با رنگ سبز، قرمز یا آبی در سمت راست کیبورد نشان می‌دهد. متن بالای صفحه هم حالا «سلام … خیلی به بازی خوش اومدی؛ موفق باشی!» است.

15. صفحهٔ ورود تازه اضافه شد (اول از همه نشان داده می‌شود و فقط ظاهری است). صفحهٔ اسم هم با سه ربات و حباب حرف و حرف‌های شناور جذاب‌تر شد.
