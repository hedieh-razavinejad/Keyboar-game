# کلیدار

سلام! این پروژهٔ من است. یک بازی حدس حرف فارسی ساخته‌ام با **Vue 3** و **Tailwind CSS**.

## بازی چطوری است؟

روی کیبورد فارسی ۳۰ تا حرف داریم. من از این ۳۰ حرف:

- یکی را به عنوان **حرف هدف** انتخاب می‌کنم،
- ۹ تا را **مین** می‌گذارم،
- ۲۰ تای دیگر **حرف امن** هستند.

بازیکن باید حرف هدف را پیدا کند. اول از همه اسم بازیکن را می‌گیرم و بعد پیام‌ها را با اسم خودش برایش می‌نویسم.

## قوانین بازی

| اتفاق | نتیجه |
|---|---|
| زدن حرف هدف | برد و امتیاز (۱۰۰ به‌اضافهٔ ثانیه‌های باقی‌مانده) |
| زدن حرف عادی | ۲ ثانیه از زمان کم می‌شود |
| زدن مین | یک جان از ۳ جان کم می‌شود |
| ورودی نامعتبر (عدد، چند حرف، حرف غیرفارسی، حرف تکراری) | کادر می‌لرزد و خالی می‌شود، چیزی از بازیکن کم نمی‌شود |
| تمام شدن ۲ دقیقه یا ۳ مین | باخت |

کادر ورودی بزرگ است و درست زیر جعبهٔ حروف قرار دارد. فقط حروف فارسی را قبول می‌کند و حرف تکراری را رد می‌کند. هر جای صفحه که با کیبورد خودت تایپ کنی، حرف داخل کادر می‌نشیند و همان کلید داخل بازی هم زده می‌شود. روی دسکتاپ کیبورد بازی بزرگ‌تر است.

تا وقتی یک حرف داخل کادر است، حرف دیگری قبول نمی‌شود. بعد از اینکه آن حرف پاک شد، حرف بعدی را می‌پذیرد.

در پایان هر دور، یک اسم فارسی مثل «تیرِ اول» یا «از دلِ آتش» نشان می‌دهم و تا سه ستاره می‌دهم.

## ربات‌ها

سه ربات دارم: اخمو، خوشحال و لپ‌تاپ‌به‌دست. زیر کیبورد، در جای خالی سمت چپ، هر کدام در یک موقعیت بیدار می‌شوند:

- لپ‌تاپ‌دار وقتی بازیکن تایپ می‌کند،
- اخمو بعد از هر اشتباه،
- خوشحال بعد از پیدا کردن حرف هدف.

صفحهٔ ورود (که فقط ظاهری است و سرور ندارد) و صفحهٔ گرفتن اسم هم ربات‌ها را دارند.

## چطوری اجرا کنم؟

نیاز به Node.js نسخهٔ ۱۸ یا بالاتر دارد.

```bash
npm install
npm run dev
npm run build
npm run preview
```

- `npm run dev` برای اجرای محلی است.
- `npm run build` نسخهٔ نهایی را در پوشهٔ `dist` می‌سازد.
- `npm run preview` نسخهٔ ساخته‌شده را نشان می‌دهد.

## فایل‌ها

```
index.html                  صفحهٔ اصلی (راست‌به‌چپ، فونت‌ها)
package.json                وابستگی‌ها و دستورها
vite.config.js              تنظیم Vite با افزونهٔ Vue
tailwind.config.js          فونت، رنگ‌ها، انیمیشن‌ها و مسیر فایل‌هایی که Tailwind می‌خواند
postcss.config.js           Tailwind و Autoprefixer
src/
  main.js                   ساخت برنامهٔ Vue
  style.css                 دستورهای Tailwind، پس‌زمینه و ظاهر کلیدها
  data.js                   حروف، متن پیام‌ها، اسم‌های پایان بازی، عددهای ثابت
  composables/useGame.js    همهٔ قوانین و وضعیت بازی
  App.vue                   چیدمان صفحه
  assets/robots/            عکس سه ربات
  components/
    LoginScreen.vue         صفحهٔ ورود (ربات با تایپ و خطا واکنش نشان می‌دهد)
    NameScreen.vue          صفحهٔ گرفتن اسم با سه ربات
    RobotTrio.vue           سه ربات کنار هم؛ فقط یکی بیدار است
    Robot.vue               یک ربات
    SideNote.vue            پیام کوتاه کنار کیبورد
    FloatLetters.vue        حرف‌های شناور پس‌زمینه
    KeyCap.vue              یک کلید کیبورد
    StatusBox.vue           جعبهٔ پیام
    ResultModal.vue         کارت پایان بازی
```

قانون‌های بازی همه در `useGame.js` هستند و کامپوننت‌ها فقط وضعیت را نشان می‌دهند.

اگر بخواهم زمان، تعداد جان‌ها یا تعداد حرف‌های امن (`SAFE_COUNT`) را عوض کنم، فقط بالای فایل `data.js` را تغییر می‌دهم. تعداد مین‌ها از روی آن خودکار حساب می‌شود. اگر بازی سخت بود، `SAFE_COUNT` را بیشتر می‌کنم.

## چیزهایی که یاد گرفتم و استفاده کردم

- **Vue 3** با Composition API و `<script setup>`: `ref`، `reactive`، `computed`، `defineProps`، `defineEmits`، `v-for`، `v-if`، `v-model`.
- **Vite** برای اجرا و ساخت پروژه.
- **Tailwind CSS** با PostCSS و Autoprefixer: کلاس‌های آماده، انیمیشن‌های `shake` و `pop` در تنظیمات، و رنگ نانی با اسم `bread`.
- **CSS ساده** فقط برای ظاهر کلیدها: سطح گود رویی، حک حرف، نور زیرین و چرخش سه‌بعدی کیبورد.
- **فونت:** شبنم، و اگر روی دستگاه نبود وزیرمتن از Google Fonts.
- از localStorage یا هیچ ذخیره‌سازی دیگری در مرورگر استفاده نکرده‌ام.
